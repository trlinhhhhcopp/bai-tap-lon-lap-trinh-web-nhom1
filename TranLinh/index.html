📌 Truy vấn 1: Xác thực đăng nhập & Kiểm tra khóa tài khoản Brute-force / Kỷ luật WHERE & CASE WHEN
Kiểm tra tài khoản người dùng đăng nhập bằng Email hoặc Mã sinh viên. Đối soát cơ chế khóa cứng (buộc thôi học) hoặc khóa mềm 30 phút. 
SELECT 
    id, user_code, name, email, role, academic_status, is_active, lock_reason, failed_attempts, is_first_login,
    CASE 
        WHEN is_active = 0 THEN 'BỊ KHÓA CỨNG (Kỷ luật Buộc thôi học / Hết khóa)'
        WHEN locked_until > NOW() THEN CONCAT('BỊ KHÓA MỀM (Còn ', TIMESTAMPDIFF(MINUTE, NOW(), locked_until), ' phút)')
        ELSE 'HỢP LỆ (Sẵn sàng đăng nhập)'
    END AS trang_thai_tai_khoan
FROM users
WHERE email = '224001729@daihocthudo.edu.vn' OR user_code = '224001729';

📌 Truy vấn 2: Hồ sơ người dùng toàn diện kèm Lớp học & Chuyên môn KTV LEFT JOIN 2 Bảng cha
Truy vấn dữ liệu hồ sơ cá nhân (Profile). Sử dụng LEFT JOIN để bảo đảm người dùng không thuộc lớp (như Giảng viên) hoặc không phải KTV vẫn hiển thị đầy đủ. 
SELECT 
    u.id, u.user_code AS ma_dinh_danh, u.name AS ho_va_ten, u.email AS email_truong, u.role AS vai_tro,
    COALESCE(c.class_code, 'N/A') AS ma_lop,
    COALESCE(c.name, 'Chưa xếp lớp') AS ten_lop_sinh_hoat,
    COALESCE(cat.name, 'Không chuyên trách') AS chuyen_mon_ktv
FROM users u
LEFT JOIN classes c ON c.id = u.class_id
LEFT JOIN categories cat ON cat.id = u.specialty_category_id
WHERE u.role IN ('requester', 'agent')
ORDER BY u.role DESC, u.id ASC LIMIT 7;

📌 Truy vấn 3: Xác thực Token SSPR khôi phục mật khẩu còn hiệu lực 15 phút INNER JOIN & WHERE
Xác thực token SHA-256 từ email. Kiểm tra token chưa hết hạn và chặn tài khoản bị đình chỉ thôi học. 
SELECT 
    pr.id AS token_id, u.user_code AS ma_sinh_vien, u.name AS ho_ten_sinh_vien,
    pr.email AS email_nhan_link, pr.token_hash AS ma_token_sha256,
    pr.expires_at AS thoi_diem_het_han, u.is_active AS tai_khoan_hoat_dong
FROM password_resets pr
INNER JOIN users u ON u.id = pr.user_id
WHERE pr.expires_at > NOW() AND u.is_active = 1 AND u.academic_status != 'expelled';

📌 Truy vấn 4: Phân tích Năng lực & Cân bằng tải Điều phối Kỹ thuật viên INNER JOIN + LEFT JOIN + GROUP BY + ORDER BY
Thống kê số phiếu thực tế đang xử lý của từng KTV và tìm KTV có ít việc nhất để phân bổ tự động. 
SELECT 
    u.id AS ktv_id, u.user_code AS ma_ktv, u.name AS ten_ky_thuat_vien,
    cat.name AS chuyen_mon_chinh, u.max_capacity AS tai_toi_da,
    COUNT(t.id) AS phieu_thuc_te_dang_xu_ly,
    (u.max_capacity - COUNT(t.id)) AS so_slot_tiep_nhan_con_lai
FROM users u
INNER JOIN categories cat ON cat.id = u.specialty_category_id
LEFT JOIN tickets t ON t.assigned_to = u.id AND t.status IN ('new', 'in_progress', 'waiting_requester')
WHERE u.role = 'agent' AND u.is_active = 1 AND u.is_on_duty = 1
GROUP BY u.id, u.user_code, u.name, cat.name, u.max_capacity
ORDER BY phieu_thuc_te_dang_xu_ly ASC, so_slot_tiep_nhan_con_lai DESC;

📌 Truy vấn 5: Thống kê Cơ cấu Sinh viên theo Khóa đào tạo & Trạng thái Học thuật GROUP BY & SUM(CASE WHEN...)
Quản lý vòng đời sinh viên: đếm số sinh viên đang học, tốt nghiệp hoặc bị kỷ luật thôi học. 
SELECT 
    u.cohort AS khoa_tuyen_sinh,
    COUNT(u.id) AS tong_sinh_vien,
    SUM(CASE WHEN u.academic_status = 'studying' THEN 1 ELSE 0 END) AS dang_hoc,
    SUM(CASE WHEN u.academic_status = 'graduated' THEN 1 ELSE 0 END) AS da_tot_nghiep,
    SUM(CASE WHEN u.academic_status = 'expelled' THEN 1 ELSE 0 END) AS bi_ky_luat_duoi_hoc
FROM users u
WHERE u.user_type = 'student'
GROUP BY u.cohort ORDER BY u.cohort DESC;

📌 Truy vấn 6: Tra cứu lịch sử phiếu hỗ trợ của SV Trần Thục Linh (Mã SV: 224001729) INNER JOIN + LEFT JOIN
Tra cứu tiến độ xử lý phiếu báo khóa cứng tài khoản sau 5 lần nhập sai do SV Linh gửi kèm ảnh thẻ SV. 
SELECT 
    t.ticket_code AS ma_phieu, req.name AS sinh_vien_gui, cat.name AS dich_vu_yeu_cau,
    t.title AS tieu_de_su_co, t.status AS trang_thai_xu_ly,
    COALESCE(ktv.name, 'Đang chờ phân công') AS ktv_tiep_nhan,
    t.created_at AS thoi_gian_gui_phieu
FROM tickets t
INNER JOIN users req ON req.id = t.requester_id
INNER JOIN categories cat ON cat.id = t.category_id
LEFT JOIN users ktv ON ktv.id = t.assigned_to
WHERE req.user_code = '224001729' OR t.is_guest_ticket = 1
ORDER BY t.created_at DESC;
